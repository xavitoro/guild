# Instrument analytics

*Canonical skill id: `instrument-analytics`*

Source of truth: [`SKILL.yaml`](SKILL.yaml) (schema `guild.skill-manifest/v1`).

## Goal

Define and implement the analytics events, properties and pipeline changes a feature requires.

## Applicable profiles

data-analytics-engineer

## Inputs

- Analytics requirement

## Outputs

- Event/property taxonomy
- Instrumentation / pipeline code change

## Steps

- Agree the event/property taxonomy with the Business Analyst and Product Data Analyst.
- Implement instrumentation and any pipeline/transformation change.
- Verify data quality against the declared taxonomy.
