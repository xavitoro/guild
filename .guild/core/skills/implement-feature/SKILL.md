# Implement a feature

*Canonical skill id: `implement-feature`*

Source of truth: [`SKILL.yaml`](SKILL.yaml) (schema `guild.skill-manifest/v1`).

## Goal

Implement new product functionality that satisfies a defined set of acceptance criteria.

## Applicable profiles

Artificer (product-software-engineer), Ranger (web-experience-engineer)

## Inputs

- Requirements and acceptance criteria
- Applicable UX/copy artifacts

## Outputs

- Code change / pull request

## Steps

- Implement the change on a branch.
- Cover the change with automated tests where practical.
- Note any technical decision that isn't obvious from the diff.
