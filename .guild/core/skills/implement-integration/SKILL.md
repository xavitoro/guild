# Implement or review an integration

*Canonical skill id: `implement-integration`*

Source of truth: [`SKILL.yaml`](SKILL.yaml) (schema `guild.skill-manifest/v1`).

## Goal

Design, implement or review an external API contract, including auth, idempotency, retries and failure handling.

## Applicable profiles

integration-engineer

## Inputs

- Integration requirement or existing integration under review

## Outputs

- Integration contract and implementation / review notes

## Steps

- Define or review the contract, including authentication and failure modes.
- Implement or verify idempotency and retry/backoff behavior.
- Document observability for the integration.
