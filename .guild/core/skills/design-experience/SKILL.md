# Design an experience

*Canonical skill id: `design-experience`*

Source of truth: [`SKILL.yaml`](SKILL.yaml) (schema `guild.skill-manifest/v1`).

## Goal

Design the user journey, information architecture and interaction specification for a requirement.

## Applicable profiles

Druid (product-experience-designer)

## Inputs

- Requirements and acceptance criteria

## Outputs

- Wireframes and screen-state specifications

## Steps

- Map the user journey against the acceptance criteria.
- Define information architecture and screen states.
- Specify interactions and transitions between states.
